# Gas Detector Circuit

## Project Description

This project uses an Arduino Uno and an MQ-2 gas sensor to detect gas levels.

## Components Used

* Arduino Uno
* MQ-2 Gas Sensor
* Red LED
* Green LED
* Buzzer
* Breadboard
* Jumper Wires
* Resistor

## Working

When the gas sensor detects a value above the set threshold, the red LED turns on and the buzzer sounds. Otherwise, the green LED turns on.
